TTryOn Lab虚拟试装工作台

开始试一件新衣服

配置你的 API Key

照片、视频或相机，都能用来试装。先注册 Decart 账号，再把你自己的 Key 填在这里。

  1. 1

    注册账号

    前往 Decart 官网注册或登录。

  2. 2

    创建 API Key

    在 API Keys 页面新建并复制 Key。

Key 会加密保存在这台电脑上，不会写入安装包。保存时检查平台认证，不会生成图片或视频。

试装会使用你自己的账号额度。免费额度以账号页面为准，。认证成功不代表余额充足或所有模型均可使用。

配置一次，下次直接进入

三种方式试装

图片一键换装
人物照片 + 服装图，查看上身效果。
短视频换装
上传不超过 20 秒的视频，保留动态画面。
相机实时换装
打开相机，边拍边看试装效果。

已有账号？直接创建 Key 即可。以后可以从顶部“应用 → API Key 设置”更换或删除。

删除已保存的 Key？

账单记录会保留，下次使用需要重新填写 Key。
