# 安全与隐私

- 不要提交真实 `.env`、API Key、Cookie、数据库、日志、人物或衣服素材。仓库仅包含配置模板、合成测试图及维护者授权公开的展示图和打赏码；这些展示图片不进入桌面安装包。
- 后端保管永久Key，相机前端只领取受模型、来源和会话时限约束的短期凭证。凭证过期本身不会停止已建立会话。
- 服务默认只监听本机，Host/Origin检查不能代替公网认证。不要把本机服务直接转发为公开服务。
- 发起生成会把所选图片、视频或相机画面发送给Decart。视频已有音轨可能一同上传；相机不采集声音。
- 账单原始数据库位于 `data/` 或 `BILLING_DB_PATH`。备份前关闭服务并复制相关数据库/WAL文件；不要公开上传备份。
- 供应商错误采用安全提示，不将完整请求或认证头写入日志。客户端用量只作估算，平台实扣另行核对。
- 如曾把真实凭据上传到公开远端，应在供应商侧撤销并重新创建；仅删除工作区文件无法清除远端历史。
- 桌面应用不读取开发者的环境 Key 或账单路径，首次启动没有 Key 和历史账单。用户 Key 通过 Electron safeStorage 调用 Windows DPAPI 加密保存，不进入 renderer 存储；只允许配置页调用密钥 IPC，官网链接采用白名单。
- 桌面工作台由随机端口、HttpOnly SameSite 会话 Cookie 和原有来源校验保护。浏览器 renderer 禁用 Node.js，启用 sandbox/contextIsolation，拒绝外部页面导航。相机只在工作台允许视频访问，不开放麦克风。
- Windows DPAPI 不抵御当前用户账号已经被控制的情况。账单未加密，卸载默认保留用户数据；删除 Key 不删除账单。生成已提交后退出不保证取消平台任务。

报告问题时请只提供脱敏复现步骤，不要附上真实Key、认证信息或私人媒体。
