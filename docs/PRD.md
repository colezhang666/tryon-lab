# 功能约定

## 输入与生成

图片一键换装接收人物照片、服装图和可选文字要求，使用 Lucy Image 2、固定720p。两张图均需有效解码且满足10MiB/1600万像素上限。未选齐或未确认上传/费用时禁用生成；提交时锁定重复点击，实际返回图片解码后才展示并允许下载。无效新图保留旧有效图。网络结果不明时不自动重新付费生成。

视频使用 Lucy VTON 3.5。接受任意正时长且≤20秒的MP4（H.264/VP8），最多50MiB、4K总像素；客户端检查后，后台ffprobe复核。提交后显示排队/处理/完成/失败状态，查询与下载不重复提交。平台任务提交后离开页面不会取消。结果只用真正返回文件，不拿原视频替代。

## 相机

点击打开才申请相机，不申请麦克风。上传服装图并确认后才开始云端连接。默认20秒，可选10/20/30秒；计时从连接发起时开始，连接等待可占用部分时长。等待可播放帧15秒超时。停止保留本地预览；关闭相机、切页和进入后台会同时结束相机和本次实时连接。迟到结果必须丢弃和清理，不自动重连。

相机结果有可播放远端帧时才可截图。截图仅保留在当前页面内存，最多12张，支持预览、PNG下载和删除确认，刷新会清空。

## 账单

本地SQLite保存调用类型、模型、用量依据、状态、预估与记录来源。图片/视频提交前写一条记录，随后更新同一ID；下载和状态查询不新增。实时凭证签发不等于生成，用量初始未知，SDK报告的秒数仅为客户端统计。失败和未知不能当作免费。

平台实际积分由用户登录官方用量页核对，再录入消耗、余额和可选模型小计。保存核对时间，和本地预估分开。未录入时显示待核对，不放入任何预设账户余额。累计消耗与余额必须非负，小计不能超过总额。支持导出当前最多500条及最新核对值。

## 存储与权限

永久Key只在后端；本地接口检查Host/Origin与请求大小。静态文件白名单不能访问配置、源码或数据库。生成结果仅为当前后端内存缓存，需下载保留；账单可跨重启保留。媒体校验可能创建本机临时文件，正常结束清理，进程崩溃可能残留。

仅为本机单人实验工具，没有公网登录、多用户权限、充值、素材库、离线模型、人脸建档或平台硬预算。不声称生成能准确还原尺码、五官、手部或每种服装细节。
