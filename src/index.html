如何开始

  1. 回到实时试穿，打开摄像头。浏览器会请求权限，不需要麦克风。
  2. 选择一张清楚的服装图，建议先选择 10 秒。
  3. 阅读画面上传与费用说明，勾选后点击“开始试穿”。
  4. 观察右侧云端画面，需要时截图，结束时点击“停止试穿”。

密钥与照片

永久密钥由本地后端保管，不显示在网页。需要更换时，修改项目中被 Git 忽略的 .env 内 DECART_API_KEY，再重启后端。浏览器只收到受限的短期连接凭证。

相机原图、服装图和试穿画面在开始后会发送至 Decart。截图保存在当前页面内存，刷新会丢失；本工具不提供云相册。

停止与常见问题

“视频试穿”会上传 MP4（含已有音轨）和服装图，本地后端用 ffprobe 临时文件校验后转交平台，正常校验结束会删除临时文件。视频任务提交后离页不会取消；刷新网页可查询本次后端任务，重启后端会丢失任务内存记录。遇到超时先核对任务，避免重复生成。

停止试穿会结束当前云端连接、保留本地预览。关闭摄像头、切换页面或进入后台会同时关闭相机。连接中停止会使迟到结果失效；供应商结束确认可能有网络延迟。

连接失败时先检查网络、Key 与官方账号权限。后端每次启动最多签发 5 次凭证，并有签发冷却；这是本机保护规则，不表示账号余额不足。确认实际用量后再重启继续。

本机运行：在项目目录执行 npm install、npm run build、npm start，打开 http://127.0.0.1:4180。服务仅监听本机，不可直接公开部署。
